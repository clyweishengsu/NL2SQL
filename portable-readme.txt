自然语言转 SQL 本地工作台（Windows x64）

使用方法
1. 解压整个 ZIP 文件并保留其中的完整目录结构。
2. 双击“NL2SQL本地工作台.exe”。
3. 程序会自动打开浏览器并进入本地工作台。
4. 关闭程序的黑色命令窗口即可停止本地服务。

运行要求
- Windows 10 或 Windows 11，64 位。
- 无需安装 Python、Node.js 或数据库客户端。
- 电脑需要能访问用户自己的 MySQL 数据库和所配置的大模型接口。
- 建议使用只有 SELECT 权限的 MySQL 专用账号。

数据存储
- 用户的连接信息和元数据保存在：%LOCALAPPDATA%\NL2SQLWorkbench\data
- MySQL 密码和模型 API Key 只保存在当前程序内存，重启后需要重新输入。
- 删除上述 data 目录可清空本机配置。

安全说明
- 本地服务只监听 127.0.0.1，不向局域网开放。
- 提问时会把问题和相关库表元数据发送给用户配置的大模型服务，查询结果行不会发送给模型。
- 首次运行未经数字签名的内部测试版时，Windows 可能显示安全提示。
